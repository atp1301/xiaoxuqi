# 5 分钟 MVP 演示脚本

1. **问题与边界（30 秒）**：本项目研究多 Agent 的编排、状态同步和工具边界。当前演示是本地模拟靶场，不代表真实环境漏洞利用效果。
2. **启动（30 秒）**：按 README 的命令启动 CLI 或 Web 页面。展示无 API Key、无额外依赖也能运行。
3. **执行过程（1 分钟）**：观察侦察、分析、验证、报告角色依次执行。解释每个角色的输入、工具权限和输出。
4. **结构化证据（1 分钟）**：打开 JSON 状态与 Markdown 报告，展示目标、服务、发现、工具结果和执行记录。
5. **安全与恢复（1 分钟）**：展示测试结果，说明范围外目标被拒绝、失败有界重试、工具调用可审计。
6. **与范本对比（30 秒）**：参照 `reference-analysis.md`，说明借鉴 PentestAgent 的哪些结构、为什么当前不直接引入全部依赖。
7. **下一步（30 秒）**：接入模型和真实授权靶场，补充真实数据，对比单 Agent 与多 Agent 的成功率、耗时、工具调用数和成本。

不要将模拟的发现、权限或 flag 描述为真实主机上的结果。
